# 尹锴冬至祝福网站

这是一个可直接静态部署的单页祝福网站。页面使用 Canvas 实时绘制冬夜、飞雪、冰晶，以及可由鼠标或手指擦开的霜层；八枚雪光分别对应八封冬至冬笺。

## 本地运行

直接双击 `index.html` 即可浏览主要效果。为了获得与线上环境一致的浏览器行为，也可以在当前目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 操作

- 按住霜面拖动，或者点击“擦开”。
- 点击任意雪光打开祝福，使用“上一封”“下一封”继续阅读。
- 点击“回到星图”收藏进度并继续探索。
- 八封全部阅读后，可以“从头再看”或“重新覆霜”。
- 右上角可以开启或关闭轻风铃。

页面每次刷新都会重新开始，不保存阅读记录，也不收集任何访问数据。
